All unreviewed industrial data is provisionally **restricted / access approval pending**, including content in publicly visible Git repositories.

## Cross-file precedence and separate owner decisions

- The three `Locations*.xlsx` variants and three `hyflo-progress*.xlsx` variants are distinct Git blobs; no file-date suffix is validated as a canonical or later business effective snapshot. `Segment.xlsx` versus `Segment 2026.xlsx` likewise has no approved precedence. Keep them separate until content and owner review.
- Each of eight SQL files is a distinct artifact, not an endorsed source schema. Six had static SQL identifier listings in HDP-002, while `hyflo_db.sql` and `iaas_db.sql` remain unread. A SQL dump can contain reference data, operational history, credentials, personal records and technical configuration simultaneously. **Its tables must be assessed individually before any of its records are classified as importable.** Do not run legacy SQL or infer import eligibility from a dump name.
- Distinguish physical facilities and pipelines (`topology`) from organizational units (`organization`). Coordinate and administrative code evidence must be checked against approved geographic editions, and `FID` must not be assumed to be a HidraAPI pipeline identifier.
- No operational planning, telemetry, audit history, approvals, user credentials or personal employee data may be restored as authentic business events merely from legacy archives.
