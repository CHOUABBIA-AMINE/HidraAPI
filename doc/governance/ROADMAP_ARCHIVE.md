# HidraAPI roadmap archive

## Status

HISTORICAL — byte-preserved task plans and execution evidence.

## Authority

The owner adopted the [HidraAPI functional delivery roadmap](../roadmap/ROADMAP.md)
as the sole active task source on 2026-11-10. The documents listed here are
archived in place so historical links, task anchors and evidence consumers remain
resolvable. Their embedded statuses are snapshots. This archive grants no
execution authority. Applicable business/security decisions and verified
implementation evidence remain reference material.

The immutable source snapshot is [HidraAPI commit 85ac6d3](https://github.com/CHOUABBIA-AMINE/HidraAPI/commit/85ac6d387ef5cf1421dd22a89b9c56079d665e1e).
Documentation validation checks the archived bytes against their registered
SHA-256 digests.
